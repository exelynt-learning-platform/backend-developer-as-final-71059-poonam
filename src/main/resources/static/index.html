Architecture & Specification

Key Technical Features

Collision Prevention

Automatic check prevents double-booking of any resource during overlapping time slots.

RBAC & JWT Security

Full CRUD for ADMIN; read-only and own-booking management for standard USER with JWT binding.

Stored as Decimal Value

Reservation total prices and base rates stored with high-precision BigDecimal (precision 10, scale 2) in MySQL.

Help & Details

Frequently Asked Questions

Per requirements, all reservation prices are stored as decimal values (BigDecimal with 2 decimal places) in the database and formatted as ₹X,XXX.00.

User identity is strictly extracted from the active JWT token in the SecurityContext, ensuring standard users cannot impersonate others.
